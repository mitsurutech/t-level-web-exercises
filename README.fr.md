# T Level Digital Software Development : exercices de programmation HTML, CSS et JavaScript avec code de départ

[English](README.md) | [Français](README.fr.md) | [日本語](README.ja.md) | [Español](README.es.md)

Des exercices de programmation HTML, CSS et JavaScript gratuits pour les élèves de la qualification technique T Level en développement de logiciels numériques (niveau 3) : 10 tâches, chacune avec un énoncé en anglais simple et un code de départ, rattachée aux numéros de thèmes du programme de Pearson.

## Ce que vous y trouvez

Chaque dossier est une tâche de nos leçons T Level Digital. Il contient un README qui dit quoi faire, et les fichiers de départ. Travaillez dans votre propre éditeur, et lisez d’abord la leçon si vous voulez que l’idée vous soit expliquée.

## Comment l’utiliser

1. Choisissez une tâche dans la liste ci-dessous et ouvrez son dossier.
2. Lisez son README, puis travaillez dans les fichiers de départ.
3. Bloqué ? Ouvrez l’aperçu de la leçon indiqué dans la tâche : il explique l’idée.

Les tests cachés et les corrigés ne sont pas ici. Ils restent dans le programme complet, où un enseignant peut donner une tâche, la corriger et faire un retour.
