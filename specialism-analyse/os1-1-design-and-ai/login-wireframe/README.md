# Login wireframe: HTML, CSS and JavaScript exercise for T Level Digital Software Development

> **From the lesson:** [OS 1.1: Design the product and check AI code](https://mitsurutech.co.uk/resources/t-level/dsd-os1-1-design-and-ai)

## What to do

Make a wireframe of a sign in screen for the school app. Use only boxes and text, no colours. It needs a title, an email box, a password box, a Sign in button and a link that says "Forgot password?". Change the HTML on the left and look at the preview. Keep it simple.

## Starter files

- `index.html`
- `style.css`
- `script.js`

Open `index.html` in a browser. Change `index.html`, `style.css` and `script.js` and reload the page to see the result.
