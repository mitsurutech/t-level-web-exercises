# Phone friendly: HTML, CSS and JavaScript exercise for T Level Digital Software Development

> **From the lesson:** [OS 7.1: Front-end testing](https://mitsurutech.co.uk/resources/t-level/dsd-os7-1-front-end-tests)

## What to do

This bus times page is fixed at 900 pixels wide. On a phone you must scroll sideways. 1. Change the CSS so the three boxes fit any screen. Use a width in % (percent, such as 30%) or a media query. 2. Make the window narrow to test it. On a phone size, the boxes should sit one under another or fit side by side. 3. Ask your teacher to look at your page.

## Starter files

- `index.html`
- `style.css`
- `script.js`

Open `index.html` in a browser. Change `index.html`, `style.css` and `script.js` and reload the page to see the result.
