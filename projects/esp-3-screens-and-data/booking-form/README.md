# Booking form: HTML, CSS and JavaScript exercise for T Level Digital Software Development

> **From the lesson:** [ESP task 3: Design the screen and the data](https://mitsurutech.co.uk/resources/t-level/dsd-esp-3-screens-and-data)

## What to do

This is stage 3 of the Hillside practice project. Make the booking form. Give every box a label. Limit the court to 1 or 2 and the hour to 9 to 20. Add a Book button. Make it simple for desk staff. Your teacher marks it from the preview.

## Starter files

- `index.html`
- `style.css`
- `script.js`

Open `index.html` in a browser. Change `index.html`, `style.css` and `script.js` and reload the page to see the result.
