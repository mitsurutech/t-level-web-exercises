# Dashboard: HTML, CSS and JavaScript exercise for T Level Digital Software Development

> **From the lesson:** [OS 6.2: User interface features](https://mitsurutech.co.uk/resources/t-level/dsd-os6-2-ui-features)

## What to do

Build a small football club dashboard. Show three big figures: wins, draws and losses. Draw a bar for each one, with a height that matches the number. Add a button "Add a win". When it is pressed, the win figure and the bar both change. Add a text message as feedback. Your teacher marks this task. Check this: a user can see what the page shows in five seconds.

## Starter files

- `index.html`
- `style.css`
- `script.js`

Open `index.html` in a browser. Change `index.html`, `style.css` and `script.js` and reload the page to see the result.
