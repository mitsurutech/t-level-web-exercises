# Bus prototype: HTML, CSS and JavaScript exercise for T Level Digital Software Development

> **From the lesson:** [OS 4.3: UI design: wireframes and prototypes](https://mitsurutech.co.uk/resources/t-level/dsd-os4-3-ui-design)

## What to do

Make a clickable prototype of a bus app with three screens: Home, Tickets and Pay. Home has a See tickets button. Tickets shows two tickets and has Back and Pay buttons. Pay says "Ticket bought" and has a Home button. Use the same button style on every screen. Keep a short style guide in a comment at the top of the CSS.

## Starter files

- `index.html`
- `style.css`
- `script.js`

Open `index.html` in a browser. Change `index.html`, `style.css` and `script.js` and reload the page to see the result.
