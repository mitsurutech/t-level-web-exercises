# Restyle: HTML, CSS and JavaScript exercise for T Level Digital Software Development

> **From the lesson:** [OS 6.2: User interface techniques](https://mitsurutech.co.uk/resources/t-level/dsd-os6-2-ui-techniques)

## What to do

This open day page is hard to read. Fix the CSS. Follow the five TODO notes in the CSS. Make the cards a grid with a gap and padding. Use a clear font, a bigger body size and a line-height of about 1.5. Make all text dark enough. The contrast ratio must be 4.5 to 1 or more. Give the button a hover colour and a visible focus outline. Your teacher marks this task. Check your colours with a free contrast checker.

## Starter files

- `index.html`
- `style.css`
- `script.js`

Open `index.html` in a browser. Change `index.html`, `style.css` and `script.js` and reload the page to see the result.
