# T Level Digital Software Development: ejercicios de programación en HTML, CSS y JavaScript con código inicial

[English](README.md) | [Français](README.fr.md) | [日本語](README.ja.md) | [Español](README.es.md)

Ejercicios de programación en HTML, CSS y JavaScript gratuitos para estudiantes de la cualificación técnica T Level en desarrollo de software digital (nivel 3): 10 tareas, cada una con un enunciado en inglés sencillo y código inicial, ligada a los números de tema de la especificación de Pearson.

## Qué hay

Cada carpeta es una tarea de nuestras lecciones de T Level Digital. Contiene un README que dice qué hacer y los archivos iniciales para trabajar. Usa tu propio editor, y lee antes la lección si quieres que te expliquen la idea.

## Cómo usarlo

1. Elige una tarea de la lista de abajo y abre su carpeta.
2. Lee su README y trabaja en los archivos iniciales.
3. ¿Atascado? Abre la vista previa de la lección que enlaza la tarea: explica la idea.

Las pruebas ocultas y las soluciones no están aquí. Se quedan en el currículo completo, donde un profesor puede poner una tarea, corregirla y dar comentarios.
